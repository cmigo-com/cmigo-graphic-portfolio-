BOMA SEARCH - HOSTING PACKAGE

Files:
- index.html

How to host:
1. Upload this folder to Netlify, Vercel, or GitHub Pages.
2. For Netlify: create a new project and deploy the folder containing index.html.
3. The site is a client-side prototype. Listings, accounts and favourites are stored in the visitor's browser using localStorage.

Important for production:
For real multi-user accounts, shared listings, secure passwords, image uploads, payments and admin controls, connect the site to a backend/database such as Supabase or Firebase. Do not use the localStorage authentication as a production authentication system.

Current working features:
- House search by location, type and maximum rent
- Price sorting
- House details
- Favourite listings
- Landlord sign-up/login prototype
- Add/publish a property
- Responsive navigation and sections
